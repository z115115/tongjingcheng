# 童锦程jev Android 浮窗

一个个人侧载的 Android 对话副驾。它复用 Jev 聊天助手的浮窗、辅助功能、OCR、知识库与可配置接口能力，把原有关系建议体系替换为 [`tong-jincheng-skill`](https://github.com/hotcoffeeshake/tong-jincheng-skill) 的童锦程视角。

## 核心判断框架

- 吸引力大于讨好：看持续、明确、互相的行动，不在模糊信号上无限加码。
- 给台阶：让对方有体面、可拒绝的接受方式；真诚动机优先于套路。
- 人性不可考验：不靠突袭、故意失联、查岗或冷战测试关系。
- 炫耀可能暴露不安全感：把标签和展示当概率信号，不当绝对证据。
- 成功前后是两个世界：低谷看真心，上升期保持清醒，但不把所有关系都解释成利益。
- 9 条启发式已进入离线主题路由和 Jev 判断题，包括读书/健身而非喝酒逃避、真喜欢试一次、钱和时间花在真正重要的人身上、生气后解决问题等。
- 价值排序：真诚、自律、忠诚、直接、体面。

完整原始 skill、研究资料和 MIT License 保存在 [`docs/tong-jincheng-skill/`](docs/tong-jincheng-skill/)；运行时会根据当前对话离线选取总纲和最多两张相关框架卡。

## 已实现

- 微信、QQ、X、飞书适配器；其它 App 可手动截屏识别一次。
- 正常 Android 辅助功能采集；没有可访问文本时使用本机 ML Kit 中文 OCR。
- Jev 按童锦程框架判断互动信号、推进风险、对方所需和下一步动作。
- OpenAI 兼容回复接口生成 3 条候选：真诚直接、给台阶的自然推进、保留自尊与退出空间。
- 半透明浮窗展示判断和候选；可复制或填入输入框，但绝不自动发送。
- API Key 使用 Android Keystore 加密保存。
- 聊天历史默认不落盘；关联上下文需用户主动开启。

## 权限与隐私

- 不 Hook、不使用 Xposed、不修改聊天 App、不读取聊天数据库。
- 不伪装系统辅助功能服务，不绕过目标 App 的访问控制。
- 只处理用户本人设备上、本人有权查看的内容。
- 本地 OCR 截图不会上传；只有触发分析时，提取出的文字才会发送给用户配置的 Jev 与回复接口。
- 转账、红包、收款和发送按钮永远不触碰。

## 手机端配置

1. 安装 APK 并打开“童锦程jev”。
2. 在设置中填写 Jev 判断接口。推荐选择 `TypeSafe 直连` 并填写 Jev API Key。
3. 填写 OpenAI 兼容回复接口的 Base URL、API Key、Model Name。
4. 开启辅助功能、悬浮窗权限；小米/HyperOS 还需允许自启动并关闭电池限制。
5. 在聊天页面点击“童”悬浮球分析；候选只能由本人确认后手动发送。

## 构建

需要 JDK 17、Android SDK Platform 35 / Build Tools 35：

```bash
./gradlew test assembleDebug
```

APK 输出到 `app/build/outputs/apk/debug/app-debug.apk`。
